# FileFitly

Static HTML5/CSS3/vanilla-JS website.

## Build
Install Node.js 18+ and run:
`node build.js`

## Preview
Use any static server, for example:
`npx serve .`

## Production
The generated HTML is crawlable and does not require a runtime Node server. Replace the domain/email in `build.js` if your production domain differs from https://filefitly.com.

## Important
Platform limits change. Verify current official requirements before publishing factual limit claims. Exact file-size targeting is encoder-dependent and should not be marketed as guaranteed acceptance by a third-party portal.
